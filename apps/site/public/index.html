How it works

One mind, many bodies.

Every Galahad instance is the same Galahad. Machines differ only in what their bodies can do: one has your repos, another never sleeps, another has a GPU, your phone has you.

The Mind

An append-only log of signed, content-addressed events. State is a pure function of the event set, so every replica converges on the same state, whatever order events arrive in and however often they're repeated. This is property-tested.

The Link

An encrypted mesh over Tailscale. Every request is signed by a device key. New devices pair with a one-time invite and a 6-digit code shown on both screens. If an invite is used twice, it locks.

The Bodies

Each machine advertises what it can do. Work goes where it fits, and Galahad says why: long, untrusted jobs to the always-on sandbox host; interactive work to the machine you're using.

What he can do

Built to grow with every machine, model and key you give him.

The Vault

Add an API key once and every full node can use it. It's sealed to each device's key, never stored in plaintext, and rotated automatically when a device is revoked.

Any model

Models are hired by role (planner, engineer, reviewer, swift) with fallback chains: Claude, DeepSeek, OrcaRouter, OpenRouter, local Ollama and llama.cpp, and anything else that's OpenAI-compatible.

Sandboxes

Every task gets its own container: unprivileged, no Linux capabilities, a read-only root, resource limits and a hard deadline. Network access is a deliberate choice: none, models only, or online.

Model gateway

Coding agents (OpenCode, Claude Code, Codex, Hermes) use your keys through scoped, capped, expiring tokens: galahad run -- opencode. The real key never leaves the vault.

The Ledger

Every gated action is a signed event: what, where, which quest, and the Oath's verdict. Read it from any device.

In your pocket

An installable app on your private network. Pair with a WebCrypto key that can never leave the device; chat, recall, approve devices and answer key requests from your phone.

Security

Safe by construction, not by promise.

An autonomous agent with access to every device you own needs guardrails built into its foundations. Each line below is enforced in code and covered by tests.

  • Keys never go through chat.Anything that looks like a credential is refused at the chat and memory doors and redirected to the vault.
  • Agents never hold your keys.Tools and sandboxes get scoped tokens limited to chosen providers. They expire and are revoked when the work ends.
  • He asks; he never sees.When Galahad needs a credential he files a request. You fill it in a password field; he only learns that it exists.
  • Untrusted content is data.Memories derived from the web or from other people are labeled untrusted. They can never become instructions or grant permissions.
  • Sandboxes he can't escape.uid 1000, zero capabilities, a read-only root, no access to the host or the Docker socket. Sandboxes can't reach each other. Verified against real Docker.
  • Creating is free; deleting asks.He can create what his work needs, but persistent things are never deleted without your approval. His own scratch work, he cleans up himself.
  • Every request is signed.Device keys with replay protection and a scope for each route. Signing in to the API does not mean every method is allowed.
  • He can't ship code to himself.Galahad may write his own improvements. Only releases you approve reach the fleet.

The Oath

Character is part of the architecture.

Courteous to you and to everyone he deals with on your behalf.

Candid. He tells the truth plainly, including bad news, disagreement and his own mistakes.

Humble. He says when he is uncertain, and never claims to have done what he hasn't.

Steady. Never flattering, never condescending; brief when brevity serves, thorough when it matters.

Status

Built in the open, milestone by milestone.

  1. M0One mind, many bodies

    Replicated signed log, pairing, vault, model gateway, any-model brain with fallbacks, placement, the Oath gate, secret scanning, CLI and phone app.

  2. M0½Sandbox hosts

    Hardened per-task containers on any Docker machine, models-only networking, scoped tokens, a signed ledger, oath-gated cleanup.

  3. M1A mind for every arm

    An MCP server so Claude Code, OpenCode, Codex and Hermes share one memory and one set of sandboxes, plus encrypted backups.

  4. M2The Round Table

    Quests as task graphs; parallel squires in isolated worktrees; independent review; approvals that follow you.

  5. M4The Forge, Scout and Trials

    Single-purpose squires with charters; new models tried against Galahad's own evals; measurable intelligence growth.

  6. M5Secure self-improvement

    Signed releases, canary rollout, automatic rollback. He can write his own improvements; only you can ship them.
